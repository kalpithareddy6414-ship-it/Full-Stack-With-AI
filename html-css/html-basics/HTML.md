HTML-BASICS

Creates a button with the text "Hello" inside.
```html
<button>Hello</button>
```                                
Creates a paragraph of text.
``` <p>paragraph of text</p> ```

1. Here 
```<button>```
is the opening tag 
2. Here
```</button>```
is the closing tag
3. In paragraphs spaces between words are treated as 1 space 
```<p>paragraph of text</p>

<p>paragraph   of   text

<p> 
paragraph of text
</p>
```
All 3 examples above will show the same result on the web page

**ATTRIBUTES**
Attributes modify how an HTML element behaves.

```<a href = "https://www.youtube.com/"> Link to YouTube</a>```

```<a>```
1. link to another website.
```href```
2. modifies which website is opened when clicking this link.

```<a href = "https://www.youtube.com/" target="_blank"> Link to YouTube</a>```
```target="_blank"```
3. causes the link to be opened in a new tab.
